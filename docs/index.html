One system. Three brands. Four products.

FOOO is the design system behind Open Orbit Studio, gabrielkroll.com, Meso+ and Faba Origin. Tokens are authored in Figma, versioned as JSON in this repo, and documented here — brand definition and design language alongside the primitives.

01 — Brands

Three brands, one skeleton

Scale, containers, ratios, easing, duration, radius and layering are identical everywhere. A brand owns colour, type, elevation — and its own positioning, voice and anti-references. Nothing structural moves.

Primary

Space

Dark-mode, near-black ground, one signal accent. Metropolis · Inter · IBM Plex Mono.

Worn by Open Orbit Studio, gabrielkroll.com
State Brand + foundations complete

Instrument

Agōn

04 — State

What is wired, and what is not

A design system that overstates its own readiness costs more than one that does not exist. Current honest state.

Working

Token build

Figma → tokens/tokens.json → Style Dictionary → dist/{css,js,clean}. Run with npm run build.

Working

Documentation

This site. Brand and foundations for Space, brand and deltas for Agōn, foundations for Seed.

Not wired

Distribution to consumers

Every consumer holds hand-copied hex literals. No import, no package, no symlink. See PIPELINE.md.

Decided

Public alias layer

Generated Figma names cannot be the public API — one rename breaks every consumer. Hand-authored aliases over the generated output. Not built.

Missing

Agōn tokens

No tokens/agon.json. Values live in mesoplus-site/DESIGN.md front-matter and inline CSS.

Pending

Seed brand definition

Foundations are safe to build against. Positioning, voice and design language wait on the offer behind fabaorigin.com.
